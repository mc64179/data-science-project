# Project repository checklist

- [x] Notebook or Python scripts are uploaded and organized.
- [x] `requirements.txt` is included.
- [x] At least two readable visualizations are included and shown in the root README.
- [x] README explains the research questions, methods, findings, and limitations.
- [x] Main notebooks use relative paths for local data.
- [ ] Original data providers, licences, and attribution requirements have been verified.
- [ ] A peer review has been recorded and linked to a public improvement commit.

The final two items require external evidence before the forum submission.
