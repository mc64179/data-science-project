## Featured project: London Housing Prices and Crime Patterns

**Research question:** How do housing prices change over time in the England aggregate series, and how do recorded crime counts and lower-price records vary across London boroughs in the supplied housing dataset?

The analysis converts dates, derives year and month fields, filters London boroughs explicitly for borough comparisons, and creates the figures with reproducible Python code. England's maximum monthly average price rose from **£53,901 in 1995** to **£250,410 in 2019**; the 2020 value is **£247,355** from one month only. Westminster had the highest maximum monthly crime count (**7,461**), followed by Lambeth (**4,701**) and Camden (**4,558**). There were **104 zero-crime records**, all from City of London between 2001 and 2010. Records below £100,000 were most frequent in Barking and Dagenham (**85**), Newham (**72**), and Bexley/Waltham Forest (**64 each**).

## Reproduce the featured analysis

The pinned environment was tested with **Python 3.12**; use Python 3.12 to follow these steps exactly.

```text
python -m venv .venv
# activate .venv, then:
pip install -r requirements.txt
jupyter notebook london-housing-analysis/analysis.ipynb
```

Run the notebook cells in order. The final plotting section runs `plot_london_housing.py`, which rewrites the three SVG figures in `london-housing-analysis/figures/`. That script needs only pandas and the supplied CSV, so it can also be run on its own:

```text
python london-housing-analysis/plot_london_housing.py
```

## Data sources and responsible sharing

The CSV files are course-provided exercise copies. The London Housing file appears to correspond to the public Kaggle dataset identified as [London Housing Data](https://www.kaggle.com/datasets/rohitgrewal/london-housing-data), but the course copy does not include a machine-readable licence or attribution statement. The original provider and redistribution terms for the Police, Weather, Cars, and COVID files were not included in the supplied materials. I therefore retain the source note, do not claim an open licence, and include no passwords, API keys, or private records. Anyone redistributing the raw CSV files should confirm the original provider's permission and attribution requirements first.
